# Computer-Automated Manufacturing — Integrated PLC, Robotics, and CNC System

**Course:** Computer Aided Manufacturing (IMSE 662)  
**Institution:** Kansas State University  
**Term:** Fall 2024  
**Team Project**

---

## Project Overview
This project involved the design, programming, and integration of a fully automated manufacturing cell combining a conveyor system, industrial robot arm, and CNC laser engraver. The goal was to transport a workpiece through multiple stations, perform robotic handling, and execute laser engraving with minimal human intervention.

The system integrated PLC ladder logic, robot motion programming, and manual G-code generation into a coordinated manufacturing workflow

---

## Technical Scope
- Programmed an Allen-Bradley Micro850 PLC using ladder logic
  - Set/reset coils, TON timers, and sensor-driven logic
- Integrated a Shuttleworth roller conveyor with multiple gates, lifts, and proximity sensors
- Programmed a Mitsubishi Movemaster EX robot arm
  - Defined work envelopes, taught positions, and motion sequences
- Wrote manual G-code for a CNC laser router to engrave custom geometry
- Designed and fabricated a 3D-printed fixture for repeatable workpiece handling
- Performed system-level integration and timing optimization across all subsystems

---

## Key Outcomes
- Successful end-to-end automation of part transport, engraving, and return
- Reliable coordination between PLC logic, robot motion, and CNC operation
- Demonstrated understanding of manufacturing automation sequencing and integration
- Final system cycle time of approximately 5 minutes per part

---

## Skills Demonstrated
- PLC ladder logic and industrial controls  
- Robot programming and work-cell planning  
- CNC programming (manual G-code)  
- Manufacturing system integration
