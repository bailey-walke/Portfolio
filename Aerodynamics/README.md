# Aerodynamics — Glider Design, Analysis, and Flight Testing

**Course:** Aerodynamics  
**Institution:** Kansas State University  
**Term:** Fall 2024  
**Team Project**

---

## Project Overview
This project involved the end-to-end aerodynamic design, construction, and flight testing of a fixed-wing glider optimized to maximize glide distance while carrying a prescribed payload. The project combined theoretical aerodynamic analysis, CAD-based mass modeling, manufacturing, and experimental validation through physical flight testing.

Predicted performance metrics were compared directly against measured flight data to assess model accuracy and design assumptions.

---

## Technical Scope
- Designed a conventionally configured glider using:
  - NACA 4412 airfoil (wing and horizontal tail)
  - NACA 0012 airfoil (vertical tail)
- Performed analytical calculations for:
  - Center of gravity (CG) location
  - Neutral point and margin of stability
  - Glide speed and glide angle
  - Lift and drag coefficients
- Modeled geometry and mass properties in SolidWorks
- Manufactured the glider using foam, wooden spars,
