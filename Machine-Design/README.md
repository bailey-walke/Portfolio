# Machine Design — Stress Concentration Validation Using FEA

**Course:** Machine Design I (ME 533)  
**Institution:** Kansas State University  
**Term:** Fall 2023  

---

## Project Overview
This project focused on validating theoretical stress concentration factors for a flat notched bar in axial tension using Finite Element Analysis (FEA). Analytical stress concentration curves from literature were compared directly against numerically obtained results to evaluate accuracy and modeling fidelity.

---

## Technical Scope
- Modeled notched flat bars with varying radius-to-width ratios (r/d)
- Evaluated two geometric cases: D/d = 1.1 and D/d = 1.01 
- Performed mesh convergence studies to ensure solution accuracy  
- Extracted maximum stress at the notch root and computed FEM-based Kₜ values  
- Compared FEM results to theoretical stress concentration curves  

All simulations were performed in SolidWorks Static Simulation under elastic loading conditions.

---

## Key Results
- FEM results closely matched theoretical predictions  
- Maximum percent error < 5%, with average error ≈ 2–3%  
- Stress trends followed expected behavior across all notch radii  
- Mesh refinement strategy successfully captured peak stresses at geometric discontinuities
